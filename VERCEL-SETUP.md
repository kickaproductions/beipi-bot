# Deploying the B.E.I.P.I Dashboard

1. Open the `kickaproductions/beipi-bot` repository on GitHub.
2. Choose **Add file → Upload files**.
3. Extract this ZIP, open the extracted folder, and drag all its contents into GitHub.
4. Commit directly to the `main` branch.
5. Vercel will automatically deploy the connected `beipi-dashboard` project.

## Preview limitations

This package is a working Vercel preview of the dashboard. Notes and Discord drafts use temporary server memory and may reset after a deployment or idle period. Login, permanent data, banner storage, Twitch, YouTube, Discord, and Railway bot syncing are the next integration stage. Never place bot tokens or passwords directly in the repository.
